# 정오의 결투 — VR 서부 결투 게임 컨셉 기획서

Nov 15, 2026 · @박수하

## 1\. 개요

정오의 결투는 정오 종이 울리는 순간 허리의 홀스터에서 리볼버를 뽑아 적보다 먼저 맞히는 1:1 VR 결투 게임이다. 승부가 나지 않으면 양쪽이 한 걸음씩 다가서고 다시 신호를 기다리며, 승패가 날 때까지 최대 5라운드를 반복한다. 1인 개발로 7일 안에 완성하는 것을 목표로 한다.

| 항목 | 내용 |
| :---- | :---- |
| 장르 | 1인칭 VR 반응속도 결투 (서부극) |
| 플랫폼 | Meta Quest 3 |
| 인원 | 1인 (상대는 AI 무법자) |
| 한 판 길이 | 2\~3분 |
| 조작 | 그립: 총 잡기 · 트리거: 격발 · 레이: 한 걸음 전진(텔레포트), 메뉴 버튼 |
| 결과 표시 | 승패, 반응속도(초), 점수 |

디자인 기둥은 세 가지다.

- **정적과 폭발**: 바람 소리마저 멎는 정적 끝에 종소리 한 번으로 모든 것이 터진다.  
- **몸으로 하는 드로우**: 실제로 손을 허리로 뻗어 뽑고 겨누는 동작 자체가 실력이다.  
- **좁혀지는 거리**: 라운드마다 적이 가까워지고 더 정확해져, 반복할수록 긴장이 오른다.

## 2\. 과제 요구사항 대응

최소 요구사항 세 가지를 모두 충족하며, XRI 상호작용은 요구치(2종)보다 많은 5종을 쓴다.

| 요구사항 | 이 게임의 대응 |
| :---- | :---- |
| XRI 상호작용 2종 이상 | 잡기(리볼버 뽑기), 소켓(홀스터), Activate(트리거 격발), 텔레포트 앵커(한 걸음 전진), 레이 UI(시작·다시하기) — 5종. 컴포넌트 설정은 8장 |
| 시작 → 플레이 → 끝 | 타이틀에서 결투 신청 → 대치 → 정오 신호 → 드로우·격발 → 판정 → (무승부면 전진 후 반복) → 승/패 결과 → 다시하기. 흐름도는 3장 |
| 점수·시간·승패 중 1개 이상 | 셋 다 표시한다: 승패, 신호부터 격발까지의 반응속도(초), 점수. 7장 |

## 3\. 게임 흐름

한 판은 타이틀 → 대치 → 드로우 → 판정으로 흐르고, 무승부일 때만 '한 걸음 전진'을 거쳐 대치로 돌아간다. 이 여섯 상태가 그대로 GameManager의 상태 머신이 된다.

\[embedded content: 게임 상태 흐름 · 6개 상태, 무승부 루프\]

승리·패배·반칙은 모두 결과판으로 모이고, '다시 결투'는 키 보정 없이 바로 대치로 돌아간다. 5라운드에서는 적 명중률이 100%라 무승부 루프는 최대 4번만 돈다.

## 4\. 핵심 메카닉

한 라운드는 '꽂혀 있는 총을 신호에 맞춰 뽑고, 한 발로 먼저 맞힌다'가 전부다. 아래 다섯 규칙이 그 한 순간을 만든다.

### 4.1 홀스터와 드로우

리볼버는 오른쪽 허리의 홀스터(소켓)에 꽂힌 채로 시작한다. 그립 버튼으로 손잡이를 쥐고 빼면 뽑힌다. 허리는 트래킹되지 않으므로, 홀스터는 머리 위치를 따라가되 높이는 시작 시 보정한 키의 약 60%, 방향은 몸의 좌우 회전(yaw)만 따라가게 한다.

드로우 직후에는 홀스터를 꺼서, 겨누는 도중 손이 허리 근처를 지나도 총이 다시 빨려 들어가지 않게 한다.

### 4.2 격발

총을 쥔 채 트리거를 당기면 총구에서 레이캐스트로 즉시 명중을 판정한다(히트스캔). 라운드당 한 발만 쏠 수 있고, 쏜 뒤에는 다음 라운드까지 트리거가 잠긴다. 손 떨림을 고려해 적 히트박스는 모델보다 10\~15% 크게 잡는다.

적 콜라이더는 머리 구체와 몸통 캡슐 두 개만 둔다.

| 명중 부위 | 결과 |
| :---- | :---- |
| 머리 | 승리 (보너스 \+500) |
| 몸통 | 승리 (보너스 \+200) |
| 그 외 | 빗나감 |

### 4.3 라운드 판정

신호 이후 플레이어와 적의 격발을 시간 순으로 처리해, 먼저 맞힌 쪽이 이긴다. 먼저 쏜 쪽이 빗나가면 상대에게 쏠 기회가 그대로 남는다. 같은 프레임이면 플레이어 승리로 본다.

둘 다 빗나가면 무승부로 4.4의 전진 단계로 넘어간다. 신호 후 3초 안에 쏘지 않으면 플레이어는 쏘지 않은 것으로 처리한다.

### 4.4 한 걸음 전진

무승부가 나면 총을 다시 홀스터에 꽂아야 다음 걸음 표식(텔레포트 앵커)이 켜진다. 레이로 표식을 가리켜 이동하면, 적도 같은 순간 한 걸음 걸어 나온다. 연출상 한 걸음은 0.5m이고 양쪽이 함께 다가서므로 라운드마다 거리가 1m 줄어든다.

'총을 꽂아야 앞으로 갈 수 있다'는 순서가 다음 드로우 준비를 자연스럽게 강제한다.

### 4.5 반칙

신호 전에 총을 홀스터에서 빼면 즉시 반칙패('비겁자' 결과)다. 판정은 홀스터의 '빠짐(Select Exited)' 이벤트가 신호 전에 들어왔는지로 한다.

## 5\. 정오 연출

공식 신호는 종소리 한 번뿐이고, 해의 회전·소리·진동은 그 순간까지 긴장을 쌓는 역할만 한다. 연출은 Directional Light 회전, 사운드, 컨트롤러 진동처럼 코드 몇 줄로 구현할 수 있는 것으로 구성한다.

| 단계 | 시점 | 화면 | 소리 | 진동 |
| :---- | :---- | :---- | :---- | :---- |
| 대치 | 신호 5\~8초 전 | 해(Directional Light)가 정점을 향해 회전하고 그림자가 짧아진다 | 바람, BGM | 없음 |
| 고조 | 신호 2\~5초 전 (랜덤) | 변화 없음 | BGM과 바람이 끊기고 심장박동만 남는다 | 양손에 심장박동 |
| 신호 | 0초 | 해가 정수리 위, 그림자가 발밑으로 | 종 1회 | 짧고 강하게 1회 |
| 격발 | 격발 순간 | 총구 화염 파티클 | 총성 | 반동 진동 |
| 결착 | 명중 순간 | 적이 쓰러지거나, 피격 시 화면이 붉게 페이드 | 정적 | 피격 시 길게 1회 |

2라운드부터는 해가 이미 정점이므로 '대치 → 고조 → 종'만 반복하고, 고조 구간 길이는 매번 2\~5초 사이에서 랜덤으로 정한다.

## 6\. 적 AI와 밸런스

적은 라운드가 진행될수록 빨라지고 정확해져서, 5라운드에서는 명중률 100%가 되어 결투가 반드시 끝난다. 적의 명중은 확률로 판정하고, 맞으면 총알이 플레이어 머리 쪽으로 날아오는 연출만 붙인다.

적 동작은 Mixamo 애니메이션 세 개(대기, 사격, 쓰러짐)로 끝낸다. 신호가 울리면 아래 '격발 시각'에 ±0.08초의 랜덤 편차를 더한 시점에 쏜다.

| 라운드 | 거리 (m) | 적 격발 시각 (신호 후, 초) | 적 명중률 |
| :---- | :---- | :---- | :---- |
| 1 | 10 | 1.10 | 35% |
| 2 | 9 | 1.00 | 50% |
| 3 | 8 | 0.90 | 65% |
| 4 | 7 | 0.80 | 80% |
| 5 | 6 | 0.70 | 100% |

난이도는 하나만 둔다. VR에서 손을 뻗어 뽑고 겨누는 데 0.7\~1.2초쯤 걸릴 것으로 추정하고 잡은 값이므로, 7일차 플레이테스트에서 실제 드로우 시간을 재서 조정한다. 수치는 ScriptableObject로 빼 두어 코드 수정 없이 바꾼다.

## 7\. 점수와 결과 화면

이기면 빠를수록, 정확할수록, 일찍 끝낼수록 점수가 높다. 지거나 반칙하면 점수는 0이지만 반응속도와 도달 라운드는 그대로 보여준다.

```latex
\mathrm{Score} = 1000 + \max(0,\ 1.5 - t) \times 1000 + B - 100 \times (r - 1)
```

&nbsp;

t는 신호부터 격발까지의 반응속도(초), B는 부위 보너스(머리 \+500, 몸통 \+200), r은 승리한 라운드다. 예를 들어 2라운드에 0.82초로 머리를 맞히면 1000 \+ 680 \+ 500 − 100 \= 2,080점이다.

결과판은 현상수배서 그림 한 장을 배경으로 깐 World Space 패널 하나이고, 결과에 따라 문구만 바꾼다.

| 결과 | 제목 문구 | 표시 정보 |
| :---- | :---- | :---- |
| 승리 | WANTED — 현상금 \$2,080 | 점수, 반응속도, 라운드, 명중 부위 |
| 패배 | 0.12초 늦었다 | 반응속도, 도달 라운드 |
| 반칙 | 비겁자 | 신호보다 몇 초 먼저 뽑았는지 |

결과판 아래의 '다시 결투' 버튼 하나를 레이로 누르면 바로 대치로 돌아간다.

## 8\. XRI 구성 설계

XRI Starter Assets의 XR Origin 프리팹을 그대로 쓰고, 게임 상태(3장)에 따라 인터랙터를 켜고 끄는 GameManager 하나가 흐름을 쥔다. 텔레포트와 레이 UI는 프리팹 설정만으로 동작하므로, 직접 짤 코드는 홀스터 추적, 격발, 판정, 상태 전환 네 가지뿐이다.

| 대상 | XRI 컴포넌트 | 설정 포인트 |
| :---- | :---- | :---- |
| 플레이어 | XR Origin, XR Interaction Manager, Teleportation Provider | 연속 이동·회전은 끈다. 결투 방향은 고정 |
| 홀스터 | XR Socket Interactor | 시작 시 리볼버를 선택한 상태. 머리 위치를 따라가는 추적 스크립트. 드로우 후 소켓 비활성화 |
| 리볼버 | XR Grab Interactable \+ Rigidbody | Attach Transform을 손잡이에. Movement Type은 Instantaneous(지연 없는 조준). 던지기 끔 |
| 격발 | Grab Interactable의 Activated 이벤트 | 트리거 → Revolver.Fire() → 총구 레이캐스트 |
| 전진 표식 | Teleportation Anchor 4개 (2\~5라운드 위치) | 도착 시 정면이 적을 향하도록 방향 맞춤. 해당 라운드 것만 켬 |
| 메뉴·결과판 | World Space Canvas \+ Tracked Device Graphic Raycaster, XR UI Input Module | 레이로 버튼 누르기 |
| 적 | 일반 콜라이더 \+ HitZone 스크립트 (머리, 몸통) | XRI 대상 아님. 레이캐스트로만 판정 |

잡기, 텔레포트, UI가 서로 엉키지 않도록 Interaction Layer를 Gun, Teleport, UI 셋으로 나누고 상태별로 아래처럼 켠다.

| 게임 상태 | 손 잡기 | 홀스터 소켓 | 텔레포트 레이 | UI 레이 |
| :---- | :---- | :---- | :---- | :---- |
| 타이틀 · 결과 | 끔 | 켬 | 끔 | 켬 |
| 대치 | 켬 (뽑으면 반칙) | 켬 | 끔 | 끔 |
| 드로우 | 켬 | 끔 (재흡착 방지) | 끔 | 끔 |
| 전진 | 켬 | 켬 | 총을 꽂은 뒤 켬 | 끔 |

## 9\. VR 편의성과 예외 처리

카메라는 절대 플레이어 의지와 다르게 움직이지 않는다. 이동은 텔레포트로만 하고, 총에 맞아도 시점을 쓰러뜨리지 않고 화면을 붉게 페이드한다.

타이틀에서 '똑바로 서서 트리거'로 키를 재 홀스터 높이를 맞춘다. 오른손잡이·서서 하는 플레이 기준으로만 만든다.

| 상황 | 처리 |
| :---- | :---- |
| 신호 전에 총을 뽑음 | 반칙패 |
| 드로우 중 총을 떨어뜨림 | 라운드는 그대로 진행되어 적이 쏜다. 라운드가 끝나면 총을 홀스터로 되돌린다 |
| 신호 후 3초 안에 안 쏨 | 플레이어 미격발로 처리하고 적 격발만 판정 |
| 무승부 뒤 총을 안 꽂음 | 5초 뒤 자동으로 꽂는다 |

## 10\. 아트와 사운드 방향

무대는 서부 마을 큰길 한 블록이고, 모델링은 하지 않고 무료 에셋만 조합한다. 곧게 뻗은 길이 시선을 적에게 모으고, 에셋 수집은 1일차에 끝낸다.

| 요소 | 내용 | 구하는 곳 |
| :---- | :---- | :---- |
| 배경 | 큰길 양쪽 건물 몇 채, 길 끝의 시계탑(장식) | Unity Asset Store 무료 로우폴리 서부 마을 팩 |
| 적 | 무법자 1명, 대기·사격·쓰러짐 애니메이션 | Mixamo 캐릭터와 애니메이션 |
| 리볼버·홀스터 | 리볼버 모델 1개, 홀스터는 단순 도형 | Unity Asset Store 무료 총기 모델 |
| 하늘·빛 | 기본 Skybox, Directional Light 하나 | Unity 기본 |
| 사운드 | 바람, 종, 심장박동, 총성, BGM 1곡 | 무료 효과음·음악 (라이선스 확인) |

## 11\. 7일 일정과 리스크

개발 범위는 적 1명, 5라운드, 상호작용 5종, 종소리 중심의 정오 연출, 결과판 하나이며, 이것으로 과제 요구사항을 모두 채운다. 하루 단위로 끝나는 목표로 나누고, 매일 마지막에 헤드셋을 쓰고 직접 해본다.

| 일차 | 할 일 | 끝났다고 보는 기준 |
| :---- | :---- | :---- |
| 1일 | 프로젝트와 XR Origin 세팅, 에셋 수집, 빈 거리 배치 | 헤드셋을 쓰고 거리 한가운데 서 있다 |
| 2일 | 홀스터(소켓), 리볼버(잡기), 격발(레이캐스트) | 뽑아서 쏘면 과녁 큐브 명중 여부가 로그에 찍힌다 |
| 3일 | 적 배치와 애니메이션, 히트박스, 적의 격발 | 적을 맞히면 쓰러지고, 적이 정해진 시각에 쏜다 |
| 4일 | GameManager 상태 머신, 라운드 판정, 반칙, 텔레포트 전진 | 5라운드 결투가 처음부터 끝까지 돈다 |
| 5일 | 타이틀·결과판 UI(레이), 점수 계산, 다시 결투 | 시작 → 플레이 → 결과 → 다시 결투가 끊김 없이 이어진다 |
| 6일 | 정오 연출: 해 회전, 종·심장박동·총성, 진동 | 신호 순간이 소리와 진동으로 분명히 느껴진다 |
